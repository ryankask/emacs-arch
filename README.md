# emacs-arch
Minimal Arch Linux PKGBUILD for Emacs with PGTK, native compilation, and tree-sitter.

Based on the original [emacs-git](https://aur.archlinux.org/packages/emacs-git) AUR package and heavily inspired by [Prot's version](https://github.com/protesilaos/emacs-arch-linux-pkgbuild).
